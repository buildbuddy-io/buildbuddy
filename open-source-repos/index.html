dfinity/ic

The Internet Computer blockchain client and replica software run by nodes.

wpilibsuite/allwpilib

Coverage-guided, in-process fuzzing for the JVM.

A web-based code review system for Git repositories.

world-federation-of-advertisers/cross-media-measurement

square/bazel_maven_repository

Bazel rules for representing a Maven repository from a pinned artifact list.

hermeticbuild/linux.bzl

Bazel rules for configuring and building Linux kernels from source.

cgrindel/rules_swift_package_manager

Bazel rules and utilities for using Swift Package Manager dependencies.

cgrindel/bazel-starlib

Reusable rules, macros, and APIs for Bazel repositories.

rue-language/rue

A programming language aiming for an abstraction level between Rust and Go.

carverauto/serviceradar

Open-source network management, monitoring, IT operations, and security analytics.

mull-project/mull

Mutation testing and fault injection for C and C++.

tweag/rules_nixpkgs

Bazel rules for importing packages from Nixpkgs.

bazel-ios/rules_ios

Bazel rules for building iOS applications and frameworks.

aya-rs/bpf-linker

A static linker for Berkeley Packet Filter programs.

player-ui/player

A cross-platform, server-driven UI framework.

sourcegraph/scip-clang

A precise Clang-based code indexer for C, C++, and CUDA.

tweag/rules_sh

Shell rules for Bazel.

jvolkman/rules_pycross

Bazel rules for cross-platform Python external dependencies.

keith/rules_multirun

Bazel rules for running multiple commands in parallel in one invocation.

hermeticbuild/rules_rs

Hermetic Bazel rules and toolchains for Rust projects.

thundergolfer/example-bazel-monorepo

An example Bazel monorepo spanning Go, Java, Python, Scala, and TypeScript.

antmicro/distant-bes

apple-cross-toolchain/rules_applecross

grailbio/rules_r
